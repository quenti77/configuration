# PhpStorm — Configuration de base

## Settings (`settings.zip`)

Export des settings PhpStorm à importer sur toute nouvelle installation.

### Importer les settings

`File` → `Manage IDE Settings` → `Import Settings...` → sélectionner `settings.zip`.

### Exporter les settings (mise à jour)

`File` → `Manage IDE Settings` → `Export Settings...` → écraser `settings.zip` et commiter.
