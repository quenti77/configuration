# Mon repo de configuration (Dotfiles)

Ce repo permet d'avoir un aide mémoire de ce qui est installé et comment c'est configurer.
Plusieurs systèmes ont été configuré et se retrouve dans des branches séparé. Pour fluidifier le tout
on va repartir sur une base saine et créer des dossiers lié aux outils installer. Si besoin d'avoir
une spécificité lié à un OS, il sera indiqué directement dans l'outil.
